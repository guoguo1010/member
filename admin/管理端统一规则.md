# 管理端统一规则 PRD (产品需求文档)

## 1. 引言

### 1.1 背景
为保证学会会员管理系统管理端各模块页面交互体验一致，特制定本统一规则文档。所有管理端列表页面须遵循本规则。

### 1.2 适用范围
管理端所有列表页面，包括但不限于：会员管理、角色管理、管理员管理、字典管理、登录日志、消息管理（短信/邮件/站内信）等模块。

## 2. 分页规则

### 2.1 组件样式
- **分页器位置**：列表底部居左或居右
- **分页器组成**：
  - 总条数信息（如：共 120 条）
  - 首页/上一页按钮
  - 页码数字（1、2、3...，当前页高亮）
  - 末页/下一页按钮
  - 每页条数切换下拉框

### 2.2 每页条数
- **默认条数**：20 条/页
- **可选条数**：10、20、30、50 条
- **切换交互**：切换后自动刷新列表，保持当前页或回到第1页

### 2.3 分页交互
| 交互 | 行为 |
|------|------|
| 首页 | 首页按钮禁用（已是第1页） |
| 末页 | 末页按钮禁用（已是最后一页） |
| 点击页码 | 跳转到对应页，刷新列表 |
| 切换每页条数 | 重新计算总页数，显示第1页 |

## 3. 列表排序规则

### 3.1 默认排序
- **无特殊说明情况下**，列表默认按以下规则排序：
  1. **权重倒序**（weight 字段，数值大的在前）
  2. **更新时间倒序**（update_time 字段，最新在前）
  3. **创建时间倒序**（create_time 字段，最新在前）

### 3.2 排序优先级
```
默认排序 = 权重倒序 > 更新时间倒序 > 创建时间倒序
```

### 3.3 说明
- 若列表存在 `weight` 字段，按权重倒序优先
- 若无权重字段，直接按更新时间倒序
- 若无更新时间字段，按创建时间倒序

## 4. 时间字段展示规则

### 4.1 通用规则
- **创建时间（create_time）**：字段存在则展示，格式 `YYYY-MM-DD HH:mm:ss`，有的列表页叫法不同，以列表页为准
- **更新时间（update_time）**：若字段存在则展示，不存在则不展示

### 4.2 展示格式
| 字段 | 格式 | 示例 |
|------|------|------|
| 创建时间 | YYYY-MM-DD HH:mm:ss | 2024-01-15 10:30:00 |
| 更新时间 | YYYY-MM-DD HH:mm:ss | 2024-06-20 14:25:30 |

### 4.3 时间字段说明
- 所有列表页字段表（字段说明章节）均需标注时间字段类型
- 创建时间：日期时间类型，不可筛，支持范围筛选
- 更新时间：日期时间类型，不可筛，支持范围筛选（若存在）

## 5. 其他统一规范

### 5.1 查询重置
- 所有列表页须提供「查询」「重置」按钮
- 重置后恢复默认筛选条件，刷新列表

### 5.2 空状态
- 列表无数据时，显示空状态提示（如：无数据/暂无记录）

### 5.3 加载状态
- 列表刷新时，显示 loading 遮罩或骨架屏

### 5.4 操作反馈
- 操作成功后，Toast 提示操作结果
- 操作失败后，Toast 提示错误信息

## 6. 下拉及关联数据加载规则

### 6.1 场景区分
根据使用场景，下拉类数据的加载策略分为两类：

| 场景 | 触发位置 | 加载范围 | 说明 |
|------|---------|---------|------|
| 列表页查询条件 | 筛选栏下拉 | 未删除的全部数据 | 用于筛选展示，可选任意未删除记录 |
| 新增/编辑表单 | 弹窗表单控件 | 启用且权限内的数据 | 仅展示可操作的有效数据 |

### 6.2 加载规则说明
- **列表页查询条件下拉**：加载所有**未删除**的数据，不受启用状态和权限限制，保证查询条件的完整性
- **新增/编辑表单下拉**：仅加载**已启用 + 权限范围内**的数据，未启用或无权限的关联数据不展示

### 6.3 规则对比
| 维度 | 列表页查询 | 新增/编辑表单 |
|------|-----------|--------------|
| 未删除 | ✅ 包含 | ✅ 包含 |
| 已启用 | ✅ 包含 | ✅ 必须 |
| 权限范围内 | ✅ 包含 | ✅ 必须 |

## 7. 发展来源下拉搜索规则

### 7.1 适用范围
所有涉及会员列表的页面，包括但不限于：会员管理、分组用户列表、标签会员分配等模块。

### 7.2 字段说明
- **字段名称**：发展来源
- **控件类型**：下拉选择（支持搜索）
- **加载范围**：所有未删除的机构数据

### 7.3 交互规则
- 下拉列表展示机构名称，加载全部未删除的机构数据
- 支持模糊搜索/过滤，快速定位目标机构
- 选择后可与其他查询条件组合使用

### 7.4 级联说明
- 若页面中同时存在机构类型一级筛选和发展来源二级筛选，机构类型变更时应联动重置发展来源的选中值
